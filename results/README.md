# Results directory

This directory contains compact evaluation summaries and figures, plus local
experiment outputs that are intentionally excluded from version control. Experiment
code, configurations, and protocols live under `models/` and `experiments/`.

## Start here

| Need | Start with |
| --- | --- |
| Project-wide conclusions | [`final_summary/conclusions.md`](final_summary/conclusions.md) |
| Consolidated earlier ML results | [`final_summary/final_table.md`](final_summary/final_table.md) |
| Classical ML comparison | [`ML/figures/experiment_metrics.csv`](ML/figures/experiment_metrics.csv) and [`ML/figures/`](ML/figures/) |
| Transformer study reports | [`transformer/reports/`](transformer/reports/) |
| Compact transformer result tables | [`transformer/tables/`](transformer/tables/) |
| Final three-model hybrid | See [Hybrid results](#hybrid) |
| Data-handling and publication guidance | See [Sharing results](#sharing-results) |

Read each report's cohort, label source, split protocol, and limitations before
comparing metrics. Results from different annotation snapshots or validation designs
are not a shared leaderboard.

## Directory map

when they do not expose private row-level data or reserved-set results.

| Directory | Contents |
| --- | --- |

| [`embeddings_context/`](embeddings_context/) | Earlier family-held-out embedding and context comparisons. |

### Generated and local-only outputs

These folders may contain large runs, checkpoints, raw responses, row-level predictions,
or private data. Their contents are intentionally ignored by Git and should remain
local unless specifically reviewed and approved for release.

| Directory | Contents |
| --- | --- |
| `annotation/` | Private annotation exports, reviewer mappings, and derived annotation files. Never publish this directory. |
| `annotation/legacy_exports/` | Loose historical CSV/XLSX exports formerly at the results root. Original filenames are preserved; this folder is local-only. |
| `LLM/` | Local model responses, caches, predictions, and full language-model experiment runs. |
| `hybrid/` | Generated predictions and metrics for cross-model rank ensembles. |
| `transformer/studies/` | Transformer training runs and model artifacts. |
| `transformer/analysis_exports/` | Generated row-level analyses and exports. |
| `transformer/final_studies/` | Final/pilot runs, private predictions, checkpoints, and aggregate outputs. |
| `ML/classical_studies/` | Generated classical study runs and row-level outputs. |
| `embeddings_context/cache/` | Cached local embeddings. |

Keep the results root uncluttered: it should contain only this index and the
top-level study directories. Historical CSV/XLSX exports belong in
`annotation/legacy_exports/`, where the pre-existing `results/annotation/` ignore
rule keeps them local. Their original filenames are retained to preserve provenance;
the directory is not a source of curated metrics.

## Hybrid results

The final hybrid comparison is generated by
[`models/hybrid/final_rank_ensemble.py`](../models/hybrid/final_rank_ensemble.py).
Its current local output is `hybrid/final_rank_ensemble_v2/`, containing:

- `metrics.csv` — AP, ROC-AUC, and fixed review-budget metrics for each model and
  rank combination.
- `oof_predictions.csv` — row-level predictions; local-only.
- `manifest.json` — input hashes, cohort exclusions, and protocol notes.

The earlier `final_rank_ensemble_v1/` output is retained locally as historical
provenance and is superseded by V2. V2 compares three OOF model sources. The ML scores
come from an earlier annotation artifact; 17 current records are missing and 28 shared
records have conflicting labels. Those 45 rows are excluded, leaving 2,097 matching
records with 116 positives. Treat this comparison as exploratory, not independent
confirmation. See [`models/hybrid/README.md`](../models/hybrid/README.md) for details
and reproduction instructions.

## Naming and organization

- Use lowercase `snake_case` for new summary files and descriptive, versioned
  directories for generated experiment outputs.
- Keep one study or model family per directory; do not mix raw inputs, predictions,
  metrics, and paper figures at the results root.
- Keep generated runs immutable. Write a new versioned output directory rather than
  overwriting an existing run.
- Put a short `README.md` in a result subdirectory when its cohort, output schema, or
  reproduction path is not clear from the corresponding experiment documentation.
- Keep raw model scores and per-record identifiers out of committed aggregate tables.

## Sharing results

Before committing, uploading, or sending any result:

1. Check `git status` and `git check-ignore -v <path>`; ignore rules are not a
   substitute for reviewing the file contents.
2. Inspect CSV/JSON columns and sample rows for clause text, item identifiers, labels,
   votes, rationales, reviewer mappings, or sealed-set data.
3. Confirm which label artifact, cohort, folds, and evaluation protocol produced the
   summary; include this provenance in the report or manifest.
4. Share compact aggregates and publication figures only when their source and
   disclosure status are approved.
5. Never publish credentials, private annotation exports, raw LLM responses, private
   reviewer mappings, or sealed TCP/DNS records.

Large checkpoints, matrices, fitted models, caches, raw responses, and row-level
predictions are excluded by the repository's [`.gitignore`](../.gitignore). The
corresponding workflows and manifests under `models/` and `experiments/` document
how derived outputs can be regenerated locally.
